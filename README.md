# Python Projects for Beginners

A collection of beginner-friendly Python projects developed to practice programming fundamentals, improve problem-solving skills, and gain hands-on coding experience. Each project focuses on applying Python concepts through practical implementation.

## Projects Included

- **Snake Water Gun Game** — A command-line game where the player competes against the computer.
- **Dice Rolling Game** — Simulates dice rolls using random number generation.
- **Fake News Generator** — Generates humorous, fake-news-style headlines using predefined subjects, actions, and places.
- **Number Guessing Game** — A game where the player guesses a randomly generated number.
- **QR Code Generator** — Generates QR codes from user-provided input data.
- **Quiz Game** — A question-and-answer game to test knowledge.
- **Restaurant Program** — A restaurant-related application built with Python.
- **Rock Paper Scissors** — A classic hand game played against the computer.
- **Simple Calculator** — Performs basic arithmetic operations, saves calculation history to a text file, displays previous calculations, and allows users to clear the history.

## Technologies Used

- **Python** — Programming language used to develop the projects.
- **Visual Studio Code** — Code editor used for development.
- **Git and GitHub** — Version control and project hosting.

## Getting Started

### Prerequisites

1. Install [Python](https://www.python.org/downloads/).
2. Install [Visual Studio Code](https://code.visualstudio.com/) or another Python-compatible editor.
3. Clone this repository:

   ```bash
   git clone https://github.com/Suman-oli10/python-projects-for-beginners.git
   ```

4. Navigate to the project folder:

   ```bash
   cd python-projects-for-beginners
   ```

### Running a Project

Run a Python file from the terminal using:

```bash
python number_guessing_game.py
```

Replace `number_guessing_game.py` with the filename of the project you want to run. Make sure you are using the correct file path and have installed any required dependencies.

Some projects may require additional Python libraries. Install the necessary libraries before running those projects.
